# Technocore TCLK Proof Viewer

Offline HTML receipt renderer for Technocore contribution proofs and TCLK proof JSON files.

This project is meant to complement proof generators instead of replacing them. A generator creates the signed or protocol-derived JSON. This viewer turns that JSON into a portable `report.html` that can be opened, archived, or shared without making network calls.

## Usage

```bash
node bin/tclk-proof-viewer.mjs examples/contribution-proof.sample.json --output report.html
```

The command accepts two proof shapes:

- `technocore-contribution-proof-v1`, as generated by `technoscore-did-starter`
- `technocore-tclk-proof`, as generated by offline TCLK transcript auditors

## Why this exists

Raw proof JSON is useful for machines but awkward for human review. A single offline receipt makes it easier to inspect the artifact URL, exact commit, DID, signature, contract state, and raw material in one place.

The renderer is intentionally dependency-free and does not call Technocore, GitHub, or any settlement rail. It only reads a local JSON file and writes a local HTML file.

## Verification

```bash
npm test
```

The tests cover:

- rendering a contribution proof
- rejecting placeholder commit values such as `FULL_COMMIT_HASH`
- rendering a TCLK contract table

## Security notes

- This tool does not verify DID signatures by itself.
- It does not ask for private keys, preimages, wallet seeds, or tokens.
- It escapes proof content before placing it in HTML.
- Treat the receipt as a readable companion to the source JSON, not as a cryptographic verifier.
